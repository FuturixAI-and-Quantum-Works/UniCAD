# Ingest fixtures

- `real_*.PAN`, `real_*.OND`: unmodified PVsyst files from the pvlib-python test data (https://github.com/pvlib/pvlib-python/tree/main/tests/data), BSD 3-Clause, see `PVLIB_LICENSE.txt`. ET SOLAR ET-M772BH550GL module and ChintPower CPS SCH275KTL-DO/US-800 inverter. Retrieved 2026-10-26.
- `synthetic_*`: written by hand from the structure of the real files above. The values are invented test data, not any manufacturer's ratings. Each carries `SYNTHETIC FIXTURE` in its Comment fields.

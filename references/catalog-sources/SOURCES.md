# Catalog seed sources

Retrieved 2026-10-26. `raw/` holds the files as downloaded. `extracted/` holds CSV/JSON built from them. `scripts/` has the extractors; each extracted row carries the PDF page (or source file) it came from.

Rerun all extractors from this directory:

```sh
uv run --with pdfplumber python scripts/extract_almm.py
uv run --with pandas python scripts/extract_cec.py
python3 scripts/extract_polycab_lt.py
python3 scripts/extract_polycab_solar.py
python3 scripts/extract_kei_lt.py
python3 scripts/extract_is1180.py
python3 scripts/extract_havells_ht.py
python3 scripts/extract_abb_switches.py
python3 scripts/extract_module_datasheets.py
```

The datasheet helper `unicad.ingest.datasheet` (`extract_text_and_tables`, `draft_spec`) reads further PDFs on demand; its output is not committed here.

`extracted/inverter_datasheets.csv`, `extracted/inverter_residential_datasheets.csv`, `extracted/bess_pcs_datasheets.csv`, `extracted/protection_ladders.json`, `extracted/protection_phase2.json`, `extracted/protection_p5.json` and `extracted/idt_impedance_citations.csv`, `extracted/meter_datasheets.csv`, `extracted/logger_datasheets.csv` and `extracted/protection_s0.json` were transcribed by hand from `pdftotext -layout` output of the cited pages. They have no script.

Licence column: what the source itself states. "Unstated" means the file and its landing page carry no licence or terms we could read. Read the licence notes at the end before shipping any of this.

Two phase-2 downloads exceed 20 MB: `raw/datasheets/protection/DEHN_Surge_Protection_catalogue_E2_2020.pdf` (43 MB) and `raw/datasheets/protection/ABB_OTDC_DC_switch-disconnectors_1SCC301022C0201_2024-06.pdf` (29 MB). `raw/` totals about 220 MB, so consider gitignoring `raw/` and keeping `extracted/` plus this file.

- Premier (both), RenewSys (both), Tata TP540HG10TB and the Tata brochure have their electrical tables as images or image labels. They are not in `module_datasheets.csv` and would need OCR (tesseract is installed) or manual entry.
- The Sungrow SG125HV spec table is an image, so it is not in `inverter_datasheets.csv`.
- ALMM does not give per-model wattage. `applied_model_wp` is the "(xxx Wp)" of the applied model only. Enlisted model wattage would have to be parsed from model names, which is not done because naming is not uniform.
- The CEC inverter list holds US variants (e.g. `SUN2000-100KTL-USH0 {800V}`, `SG350HX-US`). The 400/415 V India variants are missing, so use `inverter_datasheets.csv` for those.
- KEI and Polycab ratings use the IS 3961 base conditions (ground 30 °C, air 40 °C, soil 1.5 K·m/W, 750 mm depth for Polycab). Derating-factor tables are in both PDFs and were not extracted to CSV.
- Group rating factors are transcribed by hand into `src/unicad/rules/grouping.py`: KEI handbook PDF pp.19-20 (printed 36-37), single-core tables A (ground, 2-12 trefoils), B (covered trench, 1/2/3/6 racks x 1-3 trefoils) and C (open air, same), multicore tables A (trench), C (trays in air, 1/2/3/6 trays x 1-9 cables) and D (ground, 2-6); Havells industrial cables catalogue printed p.53 table 1, multicore cables laid direct in ground in horizontal formation, touching, 7-12 cables (0.52, 0.50, 0.48, 0.46, 0.45, 0.44). More circuits than one rack holds are taken on the fewest tabulated racks in tiers (an installation arrangement the finding states).
- `protection_ladders.json` vcb_36kv carries the VD4 total breaking time (<= 60 ms, PDF p.18, fixed version table).
